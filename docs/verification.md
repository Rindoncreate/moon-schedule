# Verification and reproduction

Local compiler: moonc v0.10.15+943464bfa, moon/moonrun 0.1.20261012, Windows. The installed skills are pinned to v0.10.14, so actual local compiler results are used instead of assuming the pinned syntax.

## Reproduce the independent oracle

Use Python 3.12 and `scripts/requirements-oracle.txt`. Python is only needed for development checks; the MoonBit library has no Python, browser or system-clock dependency.

```sh
python -m pip install -r scripts/requirements-oracle.txt
python scripts/generate_vectors.py --check
node scripts/verify.mjs
```

If Python or MoonBit is not on PATH, set process-local `PYTHON` and `MOON` to their executable paths. `verify.mjs` defaults MoonBit to the standard user installation.

There are 160 recurrence vectors and 40 large-offset calendar vectors, generated independently using python-dateutil 2.9.0.post0 and Python stdlib datetime. Seed: 55452026. `fixtures/reference-vectors.json` contains the inputs and expected outputs. The generated MoonBit tests assert outputs and, for nonempty windows, the anchored next occurrence. Targeted tests cover parser failures, query budgets, month ends, leap years, window phase, global COUNT and calendar overflow.

CI regenerates the reference tests, formats them and rejects an unexpected fixture/source diff before running checks. This prevents altered expected results in a test file from silently bypassing the independent reference.

## Baseline and current evidence

At upstream base `1d35dc9`, the original 12 JS tests passed. The added five normative regressions failed (12 passed, 5 failed). The original clamping test deliberately encoded behavior inconsistent with RFC recurrence; it was updated with an explicit migration note.

The contribution now has 234 MoonBit tests, including 200 generated independent vectors. The verification script runs check/build/test for JS, Wasm and Wasm GC; validates exact outputs of three consumer scenarios and CLI success/failure cases; then creates a source package. Linux CI additionally enables native with `MOON_NATIVE=1`.
